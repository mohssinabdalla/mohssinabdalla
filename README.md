## 🚀 What I've Built

**[ZAD — zadshare.com](https://zadshare.com)** · *Founder & Developer*
An academic resource library where APU students find notes, past papers and mock exams by specialization, year and course.
Built end to end with Next.js, TypeScript and Supabase — row-level security, Google sign-in, in-browser PDF preview, comments, ratings, moderator roles, an admin panel and email updates.

**PALMS — Personal Automated Life Management System**
A 20-database Notion system run by 5 AI agents connected through MCP (Model Context Protocol), auditing priorities and recommending what to focus on.

**AI Customer Service & Product Recommendation Chatbot** · *APU*
LLM-powered support bot that pulls live data from Google Sheets, product inventories and knowledge bases through API-triggered workflows.

**APU CodeCamp Management System** · *APU*
Object-oriented desktop app for managing coding coaching sessions, built as a team.
